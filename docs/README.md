# Job Tracker Documentation

## Project Structure
```
frontend/  - React frontend with TypeScript
backend/   - Spring Boot REST APIs
docs/      - Documentation files
```

## Tech Stack
- Frontend: React 18, TypeScript, Context API
- Backend: Spring Boot, JPA, MySQL
- Testing: Jest, Mockito, MockMvc

## Getting Started
1. Frontend: `npm install && npm start`
2. Backend: `mvn clean install && mvn spring-boot:run`

## API Documentation
See `BACKEND-APIS.md` for detailed API documentation.
