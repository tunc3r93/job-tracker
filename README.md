# Job Tracker 📋

Ein **Full-Stack Learning-Projekt** zur Verfolgung von Bewerbungen und Job-Anwendungen. Dieses Projekt demonstriert professionelle Softwareentwicklung mit modernen Technologien, Clean Architecture und umfassenden Tests.

---

## 🎯 Projektüberblick

**Job Tracker** hilft dabei, den Überblick über deine Bewerbungen zu behalten:
- ✅ **Neue Jobs hinzufügen** → Tracking über alle Phasen
- ✅ **Statuses aktualisieren** → Von Bewerbung bis Angebot oder Absage
- ✅ **Übersichtliche UI** → Einfache Verwaltung deines Job-Hunting-Prozesses
- ✅ **REST API** → Backend für alle CRUD-Operationen
- ✅ **Unit Tests** → Umfassende Test-Coverage für Controller & Services

---

## 🛠️ Tech Stack

### Backend
- **Java 21** mit **Spring Boot 4.0.5**
- **Spring Data JPA** für Datenbankzugriff
- **PostgreSQL** oder **MySQL** (Docker-Support)
- **Lombok** für weniger Boilerplate-Code
- **JUnit 5** & **Mockito** für Unit Tests
